# Royal Energy FC Website

Static, responsive website for Royal Energy FC Buwasa.

## Deploy on Vercel
1. Upload this folder to a GitHub repository.
2. On Vercel, import the GitHub repository.
3. Keep the framework preset as **Other** (or leave auto-detected).
4. Build command: leave empty.
5. Output directory: leave empty / root.
6. Deploy.

The site uses the supplied Royal Energy FC team photo and fixture image in `assets/`.
